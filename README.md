# 基于 SpringBoot + Vue 的车辆租赁系统 (Vehicle Rental System)

在线租车 · 车辆管理 · 订单管理 · 支付宝支付 · 车店导航 · 在线沟通 · 订单评价 · 维修记录 · 公告管理

本项目是一套面向汽车租赁公司、分时租赁平台及共享出行服务的车辆租赁管理系统，采用前后端分离架构，覆盖管理员与用户两类角色。系统围绕"车辆管理、订单管理、在线支付、车店导航、在线沟通、订单评价、维修记录、公告管理"等核心业务设计，支持用户在线浏览车辆、选择租期、支付宝在线支付、查看车店位置、与客服在线沟通，管理员负责车辆与品牌管理、订单处理、员工与车店管理、维修记录维护、数据统计与公告发布，实现从车辆上架、用户下单、支付租车、取还车到评价结算的全流程数字化管理，适用于汽车租赁公司、共享汽车平台、分时租赁服务、旅游租车平台及企业用车管理系统。

## 核心特性

- **车辆与品牌管理**：管理车辆品牌、车型、车辆类型（轿车/SUV/MPV/跑车等），维护车辆信息（车牌、颜色、排量、座位数、日租金、车辆状态），支持车辆上下架。
- **在线租车与支付**：用户浏览可用车辆，选择租期与取还车门店，系统自动计算租金，支持支付宝在线支付，支付成功后生成订单。
- **车店导航**：展示各车店位置信息（地址、联系电话、营业时间），集成地图导航功能，用户可一键导航至取车门店。
- **在线沟通**：用户与管理员/客服实时在线沟通，咨询租车问题、订单状态、车辆信息等，支持消息记录查看。
- **订单管理**：管理员查看所有订单列表，包括订单状态（待支付/待取车/租赁中/待还车/已完成/已取消）、用户信息、车辆信息、租期、租金，支持订单审核与状态管理。
- **订单评价**：用户完成还车后可对车辆与服务进行评分与评价，评价信息供管理员查看与统计分析。
- **维修记录**：管理员记录车辆维修历史，包括维修时间、维修内容、维修费用、维修状态，保障车辆安全与可追溯。
- **常见问题与租车向导**：提供租车常见问题解答与租车流程指南，帮助用户快速了解租车规则与操作流程。

## 功能模块概览

## 管理员端

管理员负责平台整体运营、车辆管理、订单管理、员工与车店管理、维修记录维护与公告发布：

### 用户与员工管理

- **用户管理**：管理注册用户信息，包括姓名、手机号、驾驶证信息、注册时间、账户状态，支持账号启用/禁用。
- **员工管理**：管理车店员工信息，包括姓名、工号、手机号、所属车店、岗位、入职时间，支持员工审核与权限分配。

### 车辆与品牌管理

- **品牌管理**：管理车辆品牌信息，包括品牌名称、品牌Logo、品牌介绍，支持品牌增删改查。
- **车辆类型**：配置车辆类型分类，如轿车、SUV、MPV、跑车、新能源车等，支持类型增删改查。
- **车辆管理**：管理车辆信息，包括车牌号、品牌、车型、颜色、排量、座位数、日租金、车辆图片、车辆状态（可用/租赁中/维修中/已下架），支持车辆上下架与批量导入。
- **车店管理**：管理车店信息，包括车店名称、地址、联系电话、营业时间、经纬度坐标、门店图片，支持车店增删改查与地图定位。

### 订单与维修管理

- **订单管理**：查看所有订单列表，包括订单状态（待支付/待取车/租赁中/待还车/已完成/已取消）、下单用户、车辆信息、租期、租金、支付方式，支持按状态、时间、用户筛选与订单审核。
- **订单评价**：查看用户对订单的评价内容、评分与标签，支持评价审核与异常评价处理，统计平均评分与服务满意度。
- **缴费记录**：查看所有用户的缴费历史记录，包括缴费时间、金额、支付方式、订单号、缴费状态，支持按时间、用户筛选与数据导出。
- **维修记录**：记录车辆维修历史，包括车辆ID、维修时间、维修内容、维修费用、维修状态、维修门店，支持维修记录增删改查。

### 沟通与公告管理

- **在线沟通**：查看与用户的在线沟通记录，回复用户咨询，支持消息分类与快捷回复。
- **公告信息**：发布平台公告，包括优惠活动通知、租车规则变更、系统维护通知、节假日安排等，支持置顶与定时发布。

## 用户端

用户面向平台注册用户，提供在线租车、订单管理、车店导航、在线沟通与评价功能：

### 账户与个人信息

- **我的信息**：查看与维护个人基本信息，包括姓名、手机号、驾驶证号、驾驶证有效期、头像，支持驾驶证信息上传与认证。

### 租车与支付

- **车辆浏览**：浏览可用车辆列表，按品牌、车型、价格、座位数等条件筛选，查看车辆详情（图片、参数、日租金、可用状态）。
- **租车下单**：选择车辆、租期（取车时间/还车时间）、取还车门店，系统自动计算租金与保险费用，确认订单信息。
- **支付宝在线支付**：订单确认后通过支付宝完成在线支付，支付成功后订单进入待取车状态，生成取车凭证。
- **缴费记录**：查看个人缴费历史记录，包括缴费时间、金额、支付方式、订单号、缴费状态，支持导出缴费凭证。

### 订单与评价

- **我的订单**：查看个人订单列表，包括订单状态（待支付/待取车/租赁中/待还车/已完成/已取消）、订单详情、车辆信息、租期、租金，支持取消订单（未取车前）与续租操作。
- **订单评价**：订单完成还车后可对车辆状况与服务进行评分（1-5星）与文字评价，支持上传评价图片。

### 车店导航与沟通

- **车店导航**：查看所有车店位置信息，包括地址、联系电话、营业时间、门店图片，点击导航按钮调用地图应用导航至车店。
- **在线沟通**：与管理员/客服实时在线沟通，咨询租车问题、订单状态、车辆信息等，查看历史沟通记录。

### 帮助与支持

- **租车向导**：查看租车流程指南，包括注册认证、选车下单、支付取车、还车结算等步骤说明。
- **常见问题**：浏览租车常见问题解答，包括租车条件、保险说明、违章处理、退改规则、押金退还等。
- **联系我们**：查看平台联系方式，包括客服电话、客服邮箱、在线客服入口、投诉建议渠道。
